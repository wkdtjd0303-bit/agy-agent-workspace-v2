2026-09-29 · 대상: !05_agy_agent/agy_agent Discord 자율 협업 AI 봇
증상
"나는 분명히 OpenCode 봇으로 세팅해뒀는데 실제로는 OpenRouter(Hermes) 봇이 동작했다."

1. 진단 요약 (Root Cause)

런타임에서 “표시되는 봇(설정)”과 “실제 실행 엔진”이 분리되어 있었다. 서로 맞물린 3가지 원인:

#원인위치결과
① 엔진-모델 정합성 가드가 OpenCode 엔진에 Hermes 전용 slug(upstage/solar-pro4 등)를 “호환”으로 오인 model_manager.py
is_model_compatible_with_engine()		 실행 불가 조합이 저장되고 런타임 OpenRouter(Hermes) 분기로 샘
② QA1/QA2/Auditor 런타임이 세션의 오래된 엔진값을 !model(SSOT)보다 먼저 읽음 trio_agent_runner.py
run_qa_turn / run_qa2_turn / run_auditor_turn		 화면은 OpenCode, 실제 호출은 agy/openrouter
③ 기동 로그/라벨이 agy 가 아니면 무조건 “Hermes”, QA2는 “OpenRouter” 하드코딩 bot.py on_ready / on_qa2_ready OpenCode 로 돌아도 로그가 Hermes/OpenRouter 로 찍혀 오동작으로 오인

실측 증거 (진단 스크립트)

SSOT(global_model_config.json · .env)는 이미 전 역할 OpenCode 였으나, 채널 세션 58개에 과거 값이 잔존했다.

 1) 전역 역할 설정 (GlobalModelManager = !model SSOT)

  qa1        opencode   opencode-go/mimo-v2.6-flash       OK
  qa2        opencode   opencode-go/deepseek-v4-flash     OK
  auditor    opencode   opencode-go/deepseek-v4.1-flash   OK

 2) 채널 세션의 stale 엔진 값 (런타임 덮어쓰기 위험)
  qa_engine      : 불일치 58건  (세션=agy         ≠ !model=opencode)
  qa2_engine     : 불일치 58건  (세션=openrouter  ≠ !model=opencode)   <-- ★ 오픈라우터 봇의 정체
  auditor_engine : 불일치 58건  (세션=agy         ≠ !model=opencode)

2. 수정 내용

2-1. 엔진-모델 정합성 가드 강화 — model_manager.py

if eng == "opencode":
    # [FIX] OpenCode CLI 는 'opencode-go/*' · 'opencode/*' 모델만 실행 가능하다.
    return owner == "opencode"        # 기존: ("/" in m) and (owner != "agy")
  • OpenCode 엔진에는 OpenCode 소속 모델만 저장 가능.
  • 위반 조합은 저장 시/로드 시 모두 자동 교정 → 거짓 OpenCode 표시 소멸.

2-2. 런타임 엔진을 !model SSOT 우선으로 — trio_agent_runner.py

# run_qa_turn
target_engine = GlobalModelManager.get_role_engine("qa1") or getattr(session, "qa_engine", "agy") or "agy"
# run_auditor_turn
target_engine = GlobalModelManager.get_role_engine("auditor") or getattr(session, "auditor_engine", None) or "agy"
# run_qa2_turn
"engine": GlobalModelManager.get_role_engine("qa2") or getattr(session, "qa2_engine", config.QA2_ENGINE) or "agy"

2-3. 표시 정직성 + 세션 정합화 — bot.py

  • _engine_display_label(): agy 외 전부 “Hermes” 로 뭉뚱그리던 표기를 실제 엔진명으로 정정 (OpenCode Coder Bot, OpenCode qa2 Bot …).
  • sync_sessions_with_global_model(): !model 변경/기동 시 모든 채널 세션의 stale 엔진 필드를 SSOT 로 정합화.

2-4. 재발 방지 테스트 — tests/test_model_routing_ssot.py (신규, 9 tests)

OpenCode×Hermes slug 비호환 · 엔진-모델 정합화 · 런타임 SSOT 우선 · 세션 치유

2-5. 진단 도구 — scripts/diagnose_model_routing.py (신규)

요약 — 원인은 ① OpenCode 엔진에 Hermes 모델 저장 허용, ② 런타임이 stale 세션 엔진값 우선, ③ 표시 라벨 오류. 수정은 정합성 가드 강화 + 런타임 SSOT 우선 + 세션 자동 치유 + 표시 정정 + 회귀 테스트/진단도구. 이제 !model 에서 고른 엔진이 표시·실행·로그 모두에서 일치한다.
